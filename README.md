# NumPy Learning Journey 🚀

Welcome to my NumPy learning journey! This repository is a collection of my hands-on practice notebooks, exercises, and mini projects as I explore the fundamentals of numerical computing and data science with Python.

## 📌 About This Repository

This repo documents my progress in learning **NumPy** — from basic array operations to more advanced techniques. It serves as both a personal reference and a portfolio of my learning.

## 🧠 Topics Covered

- Array creation and manipulation
- Indexing, slicing, and broadcasting
- Mathematical and statistical operations
- Linear algebra with NumPy
- Random number generation
- Working with real-world datasets

## 🛠️ Tools & Environment

- **Language:** Python 3.x
- **Library:** NumPy
- **Environment:** Jupyter Notebook / VS Code / Google Colab
- **Version Control:** Git & GitHub

## 🚀 Getting Started

To run the notebooks locally:

1. Clone this repository:

        git clone https://github.com/gazishawon999/numpy-learning-journey.git

2. Install NumPy (if not already installed):

        pip install numpy

3. Open the notebooks using Jupyter Notebook or VS Code.
